# 🚀 전준우의 갤러그 (CAPTAIN JUNWOO GALAGA)

아빠가 아들 **전준우**를 위해 특별 제작한 고전 아케이드 슈팅 게임 **갤러그(Galaga)** 스페셜 에디션입니다.

## ✨ 주요 특징
1. **전준우 함장 전용 우주 배경 & 홀로그램**
   - 배경에 빛나는 `★ CAPTAIN 전준우 ★` 은하 성단 워터마크와 응원 문구 커스터마이징 지원
   - **준우 골드 스타파이터**, **오리지널 화이트&레드**, **사이버 네온 블루** 3종 기체 스킨 제공
2. **8비트 레트로 사운드 & 전준우 음성 응원**
   - Web Audio API 자체 합성 8비트 출격 팡파르, 준우 우주 출격 BGM, 레이저/폭발/트랙터 빔 효과음
   - 우주 사령부의 한국어 음성 응원 (`"전준우 함장님, 출격 준비 완료!"`, `"전준우 더블 파이터 합체 성공!"`)
3. **오리지널 갤러그 핵심 재미 완벽 구현**
   - 보스 갤러그(2HP), 고에이(붉은 나비), 자코(노란 벌) 곡선 진입 및 급강하 패턴
   - **트랙터 빔 구출 & 2대 합체(Dual Fighter)** 2연사 시스템
   - 3스테이지마다 등장하는 **CHALLENGING STAGE (보너스 스테이지)**
   - 준우 전용 필살기 **⚡준우포 (스타버스트 9갈래 황금 미사일 & 보호막)**
4. **아이폰(iOS) · 아이패드(iPadOS) · PC 반응형 & 24시간 클라우드 랭킹 동기화**
   - PWA(`홈 화면에 추가`) 지원 및 모바일 터치 버튼 + 드래그 조종 패드 탑재
   - GitHub `db-store` 브랜치 및 Google Drive 연동을 통한 실시간 명예의 전당(TOP 10) 동기화
